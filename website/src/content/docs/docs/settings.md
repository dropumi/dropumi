title: Settings

These are the settings of the iPhone, iPad and Mac app, which is in development.

| Setting | What it does |
| --- | --- |
| Device name | The name nearby devices see. It is only a label: devices recognise each other by their key. |
| Who can send | Paired only, Everyone for 10 minutes, or Off. See [Visibility](../visibility/). |
| Paired devices | Devices you paired by comparing a code or added by their fingerprint. Rename or remove them here. |
| Pair a device | Pair with another device by comparing a 6-digit code once. |
| Connect by address | Reach a device that does not show up nearby. |
| Auto-accept paired devices | Skip the question for devices you paired. Off by default. Devices you have not paired always ask. |
| Save received files to | Mac only: where received files are saved. On iPhone and iPad they are in the Files app. |
| Open at login | Mac only: receive from the menu bar after you log in. |
| Appearance | Light, dark or follow the system. |

To clear the list of past transfers, use **Clear** on the [Transfers](../transfers/) screen.
