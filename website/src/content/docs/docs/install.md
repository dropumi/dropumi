---
title: Install
description: Install dropumi on desktop and mobile.
---

dropumi is planned for macOS, Windows, Linux, iOS and Android. Install it on every device you want to share between. Both devices must be on the same Wi-Fi network or hotspot.

## Desktop

Download the installer for your system from the [Releases page](https://github.com/dropumi/dropumi/releases), open it and follow the prompts. On macOS, drag dropumi into Applications.

## Build from source

```sh
git clone https://github.com/dropumi/dropumi.git
cd dropumi
```

See [Contributing](../contributing/) for build steps once the app code lands.

## Phone and tablet

Get dropumi from the App Store or Google Play. The first time you open it, allow access to the local network so it can find nearby devices.

:::tip
If a device does not show up, check that both are on the same network and that guest-network isolation is off on your router.
:::
