---
title: Receive a file
description: Accept incoming files.
---

When someone sends you a file, dropumi shows who it is from and what they are sending.

- **Accept** starts the transfer.
- **Decline** cancels it. The sender is told it was declined.

By default, only devices you paired can send to you. A device you have not paired can only ask while you allow **Everyone**, and you both compare a 6-digit code before you accept. It is never accepted automatically. See [Visibility](../visibility/).

For paired devices, dropumi asks every time unless you turn on **Auto-accept paired devices** in [Settings](../settings/).

On a Mac, received files go to the **Dropumi** folder in Downloads. You can choose another folder in [Settings](../settings/). On iPhone and iPad, they are in the Files app, under **On My iPhone** (or **On My iPad**) › **Dropumi** › **Received**.

On iPhone and iPad, dropumi receives only while it is open.
