---
title: Contributing
description: Help build dropumi.
---

dropumi is open source and contributions are welcome.

- **Report a bug or suggest a feature:** [open an issue](https://github.com/dropumi/dropumi/issues).
- **Send code:** fork the repo, make your change and open a pull request.
- **Improve the docs:** every docs page has an **Edit page** link at the bottom.
- **Design:** brand assets and UI designs are in the `branding/` folder. See `design.md` for colors and type.
