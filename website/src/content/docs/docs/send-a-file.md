---
title: Send a file
description: Send files to a nearby device.
---

1. Open dropumi on both devices.
2. On the sender, wait for the receiving device to appear on the radar.
3. Drop a file onto the window, or tap **Send** and choose files.
4. Tap the receiving device.
5. The receiver sees a prompt. When they accept, the transfer starts.

You can send several files at once. Progress shows on the **Transfers** screen.
