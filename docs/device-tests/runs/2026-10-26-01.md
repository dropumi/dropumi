## Findings

1. **Open: `android_nsd_app_finds_cli_and_sends` fails intermittently.**
   - The test timed out waiting for "the CLI nearby": the app listed no device (`nearby 0`).
   - It also failed on 2026-10-18 and 2026-10-25.
   - The cause is not established. `android_nsd_cli_finds_app_at_random_host` passed, but with the R21 gate closed it
     only shows that the app does not advertise.
2. **Environment: the phone's screen must stay on.** An earlier `ui-tests.sh` run the same day failed 111 tests with
   "No compose hierarchies found" and the activity STOPPED, because the phone's screen locked during the run. This was
   the environment, not the code. The run above kept the screen on with `svc power stayon usb` and set it back
   afterwards.
3. **Not runnable on this phone (by design):** the two hard-link `UriGuard` tests (`link()` inside the app's data
   returns `EACCES`, as on the arm64-v8a emulators) and `LockScreenTest#promptNeverShowsOverTheLockScreen` (the phone
   has a secure lock screen).
4. The notes about moving the repository to another drive are in [2026-10-25-01](2026-10-25-01.md), Finding 5.
